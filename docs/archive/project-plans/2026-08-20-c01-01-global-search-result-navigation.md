# C-01-01 搜索结果模型与精确定位

日期：2026-08-20  
状态：已归档，待执行

## 目标

让全局搜索结果直接打开任务、笔记、书籍或视频的具体对象，而不是只切换到模块首页。

## 输入与范围

- `src/App.tsx` 搜索查询和结果动作。
- 任务、笔记、书籍、视频当前的选中对象和打开函数。
- 必要时增加模块级 deep-link 事件或 store 状态。

本任务不负责排序、FTS、键盘导航或搜索范围扩展。

## 实现步骤

1. 定义统一搜索结果类型，包含 `id`、`module`、`title`、`description` 和 `action`。
2. 四类 SQL 查询返回实体 ID及必要的打开字段。
3. 将任务结果映射到任务详情抽屉，笔记结果映射到指定笔记，书籍结果映射到指定阅读器，视频结果映射到指定详情抽屉。
4. 对无效或已删除对象提供回退提示，并关闭搜索面板。

## 验收标准

- 每类结果点击后打开对应对象。
- 不通过标题二次查找，不依赖用户手动筛选。
- 对象不存在时不会打开错误对象，且有明确提示。
- `/task` 和 `/note` 命令动作不受影响。

## 测试证据

- 四类对象各一个定位测试。
- 无效 ID 回退测试。
- `npx eslint src/App.tsx src/components/Topbar.tsx` 通过。

## 依赖与风险

- 可能需要暴露模块已有的选中对象 setter 或 deep-link 事件。
- 若模块只能异步加载，必须确保 deep-link 在模块完成加载后仍然生效。
