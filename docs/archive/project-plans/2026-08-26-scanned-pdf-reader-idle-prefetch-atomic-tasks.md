# 扫描版 PDF 阅读器空闲预取原子任务清单

日期：2026-08-26  
状态：已归档，执行中  
来源：[扫描版 PDF 阅读器空闲预取与不对称窗口方案](./2026-08-26-scanned-pdf-reader-idle-prefetch-plan.md)

## 一、执行原则

- 任务严格串行；每项完成后先审查范围，再执行完整门禁并独立提交。
- 每项只承担一个主要行为变化，禁止把未验证的后续优化混入当前提交。
- 不重新引入“先只渲染目标页，再切换回邻页”的两阶段模式。
- 过期异步任务必须通过会话/代次校验隔离，不能依赖更换 React key 强制修复。
- 文档中的完成记录只在对应任务真正完成后更新。

## 三、任务详情

### PDF-IDLE-01 不对称候选窗口模型

目标：将连续阅读的默认候选范围从前后各 4 页调整为当前页前 1 页、后 3 页，并保持目标页优先和页数边界正确。

范围：

- 在渲染调度器中增加前后独立窗口参数或等价的纯函数输入。
- 默认连续模式生成 `[target-1, target, target+1, target+2, target+3]` 的候选优先级。
- 保留可见页优先、目标页优先、自动阅读兼容和文档首尾裁剪。
- 更新调度器单元测试，覆盖中心页、首尾页、可见页和连续跳转。

验收：最多 5 个默认候选页；当前页必须是第一项；后续页排在前置页之前；旧的 9 页默认窗口不再由连续模式使用。

### PDF-IDLE-02 PDF 连续滚动空闲状态

目标：在不延迟页码和导航反馈的前提下，建立 400ms 的滚动稳定状态。

范围：

- 增加 PDF 连续模式滚动状态及空闲计时器。
- 每次滚动立即标记未稳定，清理上一轮计时器；最后一次滚动 400ms 后标记稳定。
- 保留当前页引用、页码和阅读进度的现有短延迟更新。
- 在卸载、书籍切换、布局切换时清理计时器和状态。
- 用可注入或 fake timer 测试验证 400ms 边界与再次滚动重置。

验收：滚动期间状态为未稳定；400ms 内再次滚动不会进入稳定；稳定后可以通知候选调度恢复；页码反馈不等待 400ms。

### PDF-IDLE-03 空闲门控与过期任务取消

目标：滚动期间不启动邻页后台工作，停止 400ms 后才处理候选，并让新滚动取消旧候选影响。

范围：

- 将连续列表的候选 overscan 在未稳定状态收缩为当前页/必要可见页，稳定后恢复前 1 后 3。
- 未知页面在未稳定状态不创建文本层；已知文本页和已知扫描页保持原语义。
- 新滚动时收缩旧调度窗口，阻止过期邻页继续准入；异步完成回调不得更新过期任务结果。
- 保证显式 OCR、目录 OCR、批注恢复和单页/双页模式不受影响。
- 增加源码契约和调度集成测试，覆盖快速连续滚动、稳定恢复和文本层门控。

验收：滚动期间不新增候选页 `getTextContent()` 路径；停止 400ms 后候选恢复；重叠缓存页不重复处理；旧候选结果不会覆盖新目标。

### PDF-IDLE-04 完整性能验证与归档

目标：证明方案满足行为和性能目标，并留下可复核的归档记录。

范围：

- 使用固定 PDF 样本验证快速滚动、稳定停留、远跳、首尾页、文本 PDF、扫描 PDF、隐藏 OCR、显式 OCR 和自动阅读。
- 运行针对性测试、`npm test`、`npm run lint`、`npx tsc -b --pretty false`、`npm run build`、`git diff --check`。
- 在 `docs/archive/qa/` 记录候选窗口、400ms 门控、取消行为、失败项和残余风险。
- 回写本清单每项完成日期、提交、审查、验证和后续风险。

验收：所有门禁通过；没有引入两阶段视图切换；性能记录能证明滚动期间候选工作减少，且阅读能力无回归。
