# 周期任务与普通父子任务统一模型原子任务

状态：已归档（2026-08-20）

配套方案：`docs/archive/project-plans/2026-08-20-recurring-task-unified-model.md`

## 1. 原子任务拆解原则

每个任务只改变一个明确的责任边界，具备独立输入、实现、验证和回滚范围。任务按依赖顺序排列，后续任务不得绕过前置数据模型和迁移任务。

## 2. 原子任务清单

### AT-01：冻结现有数据语义与迁移基线（已完成）

- 输入：现有 `tasks`、`recurring_rules`、`recurring_instances`、`recurring_rule_steps` 数据。
- 工作：盘点旧字段组合、重复数据、孤立根、错误步骤 `instance_key`，输出迁移前后映射。
- 验收：提供真实库统计；明确每种旧形态对应的新类型；不修改业务数据。
- 依赖：无。

### AT-02：增加任务类型和关系类型字段（已完成）

- 输入：AT-01 映射。
- 工作：增加 `task_kind`、`relation_kind`、周期来源字段（或将现有 `recur_rule_id` 统一命名为来源字段），建立默认值和合法值校验。
- 验收：新建普通任务、日期实例、时间执行项均能写入正确类型；非法组合被拒绝。
- 依赖：AT-01。

### AT-03：迁移历史任务类型（已完成）

- 输入：AT-01 映射、AT-02 字段。
- 工作：将日期级周期根迁移为 `recurring_date_instance`，时间根迁移为 `recurring_execution`，其它任务迁移为 `normal`。
- 验收：迁移可重复执行；历史完成状态、父子关系和标题保持不变。
- 依赖：AT-02。

### AT-04：启动时归并重复日期实例（已完成）

- 输入：旧版重复 `recurring_instances`。
- 工作：同一 `(rule_id, date_key)` 只保留一个实例，将任务引用迁移到保留实例后删除重复实例。
- 验收：重启后每个规则日期只有一个日期实例；已完成状态按保留记录规则处理且不丢失。
- 依赖：AT-03。

### AT-05：启动时修复孤立根和重复时间项（已完成）

- 输入：旧版孤立时间根、重复执行项和旧索引。
- 工作：先移除阻塞旧索引，再把孤立根挂到日期实例，归并重复时间项，迁移后代，最后重建索引。
- 验收：旧库可以启动；孤立根不再出现在顶层；重复时间项只保留一条；迁移幂等。
- 依赖：AT-03、AT-04。

### AT-06：建立数据库唯一约束和结构约束（已完成）

- 输入：清理后的数据。
- 工作：建立 `(rule_id, date_key)` 和 `(rule_id, recurring_instance_id, instance_key, parent_id)` 唯一索引；增加类型关系触发器或事务校验。
- 验收：重复日期实例和重复时间项插入失败；普通任务不会被错误写入周期关系。
- 依赖：AT-05。

### AT-07：统一调度器二维生成和幂等补齐（已完成）

- 输入：周期规则日期集合、每日时间集合、AT-06 约束。
- 工作：按“符合规则的日期 × 执行时间”生成；重启复用已有实例；只补缺失时间项和步骤，不重写历史完成状态。
- 验收：单日多次、多日多次、重启三次均不重复；新增规则步骤能补齐到已有未来执行项。
- 依赖：AT-06。

### AT-08：拆分周期步骤与普通子任务语义（已完成）

- 输入：现有 `recurring_rule_steps` 和生成逻辑。
- 工作：优先设计 `task_execution_steps`；过渡期间为步骤增加明确类型并清空 `instance_key`，阻止步骤进入普通任务树统计。
- 验收：多个步骤可以属于同一执行项；步骤不影响执行项唯一性；步骤不被识别为普通子任务。
- 依赖：AT-02、AT-07。

### AT-09：统一任务类型判断 API（已完成）

- 输入：AT-02 类型字段。
- 工作：实现 `isNormalTask`、`isRecurringDateInstance`、`isRecurringExecution`、`isManualChildTask`、`isRecurringStep`、`isActionableTask` 及集合查询函数。
- 验收：主列表、看板、日历、便签不再直接组合字段判断；所有视图使用同一套 API。
- 依赖：AT-02、AT-03。

### AT-10：重构主面板展示（已完成）

- 输入：AT-09 查询 API。
- 工作：日期实例显示为周期主任务；“当日 N 次”展开时间执行项；普通父子任务继续使用普通子任务区域；标题、时间和状态不重叠。
- 验收：单日和多日周期结构正确；周期执行项不计入普通子任务数；普通父子任务标题可不同。
- 依赖：AT-07、AT-09。

### AT-11：重构其它页签和桌面便签过滤（已完成）

- 输入：AT-09 `getActionableTasks`。
- 工作：隐藏周期日期实例，显示周期执行项；显示普通父任务和普通子任务；默认隐藏周期步骤。
- 验收：便签和其它页签不出现周期容器；普通父子任务完整显示；同一周期不会重复展示容器和执行项。
- 依赖：AT-08、AT-09。

### AT-12：统一完成、编辑、删除、跳过范围（已完成）

- 输入：AT-09 类型判断、现有操作流。
- 工作：周期执行项操作只作用于完整 occurrence；日期实例只汇总；普通父子任务继续使用普通树操作；周期规则删除作用于规则整体。
- 验收：完成一个时间项不影响其它时间项；跳过不影响同日其它时间；修改当天不改规则；普通子任务操作不触发周期例外。
- 依赖：AT-07、AT-09、AT-10。

### AT-13：重构创建/编辑抽屉文案和分区

- 输入：两种任务业务边界。
- 工作：普通任务模式显示任务信息、父任务挂靠、普通子任务；周期任务模式显示重复规则、执行时间、执行步骤、有效期。
- 验收：用户不会把执行项误认为普通子任务；编辑范围清楚显示当天、未来、全部的区别。
- 依赖：AT-08、AT-12。

### AT-14：建立回归测试矩阵

- 输入：所有前置验收标准。
- 工作：补齐数据库迁移、调度器、列表、便签、完成隔离、普通父子任务和多日多次测试。
- 验收：至少覆盖：同日多个时间点、3 天 × 3 次、重启幂等、历史旧数据、重复约束、便签过滤、普通父子显示、完成隔离。
- 依赖：AT-04 至 AT-13。

### AT-15：发布前迁移演练与文档收口

- 输入：真实用户数据库备份、AT-14 测试结果。
- 工作：演练备份、启动迁移、失败恢复、日志检查和 UI 验收；更新用户迁移说明和开发维护文档。
- 验收：可从旧数据库恢复；迁移前后数量和状态有对账；构建、类型检查、回归测试全部通过。
- 依赖：AT-05、AT-06、AT-14。

## 4. 验收矩阵

| 场景 | 预期结果 | 覆盖任务 |
|---|---|---|
| 单日两次 | 1 个日期实例、2 个时间执行项 | AT-07、AT-10、AT-14 |
| 三天每天三次 | 3 个日期实例、9 个时间执行项 | AT-07、AT-14 |
| 重启调度 | 数量不增加 | AT-06、AT-07、AT-14 |
| 历史孤立根 | 启动归并到日期实例 | AT-03 至 AT-05、AT-14 |
| 重复日期实例 | 保留一个并迁移引用 | AT-04、AT-14 |
| 重复时间项 | 唯一约束拒绝或启动归并 | AT-05、AT-06、AT-14 |
| 周期便签 | 只显示时间执行项 | AT-08、AT-11、AT-14 |
| 普通父子便签 | 父、子都显示，各自标题 | AT-09、AT-11、AT-14 |
| 完成一个时间项 | 其它时间项状态不变 | AT-12、AT-14 |
| 普通子任务完成 | 只更新普通父任务进度 | AT-12、AT-14 |
