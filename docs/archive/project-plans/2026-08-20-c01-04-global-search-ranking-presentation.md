# C-01-04 相关性排序与结果呈现

日期：2026-08-20  
状态：已完成，已归档
所属计划：[C-01 全局搜索原子任务计划](2026-08-20-c01-global-search-atomic-tasks.md)

## 目标

让最相关的结果优先展示，并让用户理解结果为什么被命中以及是否还有更多结果。

## 实现步骤

1. 实现标题完整匹配、前缀匹配、标题包含、其他字段包含的确定性评分。
2. 同分按更新时间倒序，保证排序稳定。
3. 按任务、笔记、书籍、视频分组并显示每组计数。
4. 显示命中字段或摘要；超过当前展示上限时提供“查看全部”。
5. 保留结果模块标签和必要的状态信息。

## 验收标准

- 标题完整匹配始终优先于正文弱匹配。
- 相同数据和查询多次执行得到相同顺序。
- 用户能看出命中字段或摘要来源。
- 截断结果不会伪装成全部结果。

## 测试证据

- 排序函数边界测试。
- 模块计数和截断提示测试。
- 中文、英文、空字段和相同更新时间测试。

## 完成证据

- 已实现标题精确、前缀、包含及其他字段包含的确定性评分。
- 同分按更新时间、模块、标题和实体 ID 稳定排序。
- 搜索结果按模块分组，使用 `COUNT(*) OVER()` 返回真实计数，每组展示 3 条并在截断时提供“查看全部”。
- 结果显示本地化命中字段及上下文摘要。
- `npx tsc --noEmit -p tsconfig.app.json`、定向 ESLint、7 项搜索测试和 `npm run build` 通过。
