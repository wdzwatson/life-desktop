# C-01-03 键盘导航与可访问性

日期：2026-08-20  
状态：已归档，待执行  
所属计划：[C-01 全局搜索原子任务计划](2026-08-20-c01-global-search-atomic-tasks.md)

## 目标

让搜索弹层在鼠标、键盘和屏幕阅读器下都具备完整可操作闭环。

## 实现步骤

1. 将输入建模为 combobox，将结果容器建模为 listbox，将结果建模为 option。
2. 增加 ArrowUp/ArrowDown、Home/End、Enter、Esc 操作和当前结果视觉状态。
3. 给顶部搜索入口和弹层输入设置稳定本地化 `aria-label`。
4. 关闭弹层后将焦点恢复到触发按钮。
5. 在 390px 宽窗口下检查输入框、清除入口和结果文本的布局。

## 验收标准

- 全程无需鼠标即可打开搜索、选择结果、执行和关闭。
- 当前结果具有可感知的焦点/选中状态。
- 屏幕阅读器能识别入口、输入框、结果数量和当前结果。
- Esc 关闭后焦点不丢失。
- 窄窗口无横向溢出，搜索按钮仍有可访问名称。
